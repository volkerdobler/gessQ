# GESS Q. 1.0.3

Prefer English? Jump straight to the [English version](#english) below.

## Neu in 1.0.3: eigene JavaScript-Module bekannt machen

Mit der neuen Einstellung **`gessq.embeddedLanguages.declarationFiles`** kennt die Hilfe in `javascript=`- und `jsHandler=`-Blöcken auch **eigene Module**. Deren Optionen werden einmal in einer TypeScript-Deklarationsdatei (`.d.ts`) beschrieben. Danach bietet z. B. `SEQdot.settings = { ` + `Strg+Leertaste` alle Optionen mit Typ und Beschreibung an, und der Hover erklärt sie. Ein Snippet pro Option ist nicht nötig.

- Einrichten in den Einstellungen, z. B. `"gessq.embeddedLanguages.declarationFiles": ["~/gessq-declarations"]`. Ein vollständiges Beispiel einer Deklarationsdatei steht in der README.
- Die Dateien bleiben lokal (User-Einstellungen) oder liegen im Fragebogen-Projekt (`.vscode/settings.json`). Mit der Erweiterung wird nichts davon verteilt.
- Ein Ordner lädt alle `*.d.ts` darin. Mehrere Dateien dürfen dasselbe `interface` erweitern, sodass jedes Modul seine eigene Datei haben kann.
- `~`, `${userHome}`, `${workspaceFolder}` und projektrelative Pfade sind erlaubt. Änderungen an den Dateien wirken sofort.
- Nur Deklarationen (`interface`, `declare var`, `declare function`, …), kein `import` / `export`.

## Highlights seit 1.0.0

- **Hover** zu praktisch jedem Schlüsselwort: Kurzsyntax, ein bis drei Sätze Erklärung und ein Link ins GESS-Q.-Handbuch. Bei einer eigenen Frage, einem Block oder Makro zeigt der Hover, wo sie definiert sind – ein Klick springt dorthin.
- **Vorschläge beim Tippen**, unter anderem die Antwortcodes einer Frage nach `FRAGE.` bzw. `FRAGE eq` / `ne` / … und die passenden Attribute innerhalb einer `labels=`-Liste.
- **Navigation über `#include` hinweg**: Gehe zu Definition (`F12`), Alle Verweise (`Shift+F12`), Umbenennen (`F2`), Symbol-Suche (`Strg+T`), Gliederung (`Strg+Shift+O`).
- Eine **„N Verweise"-Zeile** über jeder Frage-Definition.
- **Fehlerhinweise**: unbalancierte Klammern, `#macro`/`#ifdef` ohne passendes Ende, fehlende `#include`-Dateien, doppelte Namen, unbekannte `#domacro`-Ziele, Präprozessor-Direktiven, die nicht am Zeilenanfang stehen.
- **Echtes JavaScript / CSS** in `javascript=`, `jsHandler=` und `css=`: Hover, Vervollständigung und Parameterhinweise wie in einer echten `.js`- bzw. `.css`-Datei – inklusive der GESS-Q.-Globals (`QDot`, `$`, `Android`, `hideq`, …).
- **Ein- und Ausklappen** von `#macro`- und `#ifdef`-Bereichen, `{ … }` und Blockkommentaren; Snippets für Fragetypen, ActionBlöcke, Grids und mehr; experimentelle Auto-Einrückung über „Dokument formatieren".
- Dieses „Was ist neu?"-Fenster öffnet sich künftig einmal pro Version automatisch und lässt sich mit der Checkbox darin dauerhaft abstellen.

## Die wichtigsten Einstellungen

Über *Datei → Einstellungen → Einstellungen* nach „GESS Q." suchen:

- **`gessq.hover.referenceDetail`** (Standard `definition`) – wie viel der Hover bei einer Frage/Variable zeigt: `off`, `summary` (nur Name und Fundort), `definition` (zusätzlich ein Auszug der Definition) oder `full` (alles).
- **`gessq.codeLens.definitions`** (Standard `questions`) – über welchen Definitionen die „N Verweise"-Zeile erscheint: `off`, `questions`, `reusable` (auch Blöcke/Makros) oder `all`.
- **`gessq.completion.autoTrigger`** (Standard `off`) – ob Vorschläge von selbst aufpoppen: `off` (nur mit `Strg+Leertaste`), `trigger` (auch nach `#`/`@`/`&`) oder `full` (auch nach einem Leerzeichen).
- **`gessq.embeddedLanguages.enable`** (Standard an) – echte JavaScript-/CSS-Hilfe in `javascript=`/`jsHandler=`/`css=`-Blöcken.
- **`gessq.diagnostics.enable`** (Standard an) – Fehlerhinweise an- oder ausschalten.
- **`gessq.releaseNotes.showOnUpdate`** (Standard an) – dieses Fenster nach einem Update automatisch zeigen.

## English

### New in 1.0.3: make your own JavaScript modules known

With the new setting **`gessq.embeddedLanguages.declarationFiles`**, the help inside `javascript=` and `jsHandler=` blocks also knows **your own modules**. Describe their options once in a TypeScript declaration file (`.d.ts`). After that, `SEQdot.settings = { ` + `Ctrl+Space` offers every option with its type and description, and hover explains it. No snippet per option is needed.

- Set it up in your settings, e.g. `"gessq.embeddedLanguages.declarationFiles": ["~/gessq-declarations"]`. The README has a complete example of a declaration file.
- The files stay with you (user settings) or live in the questionnaire project (`.vscode/settings.json`). None of it is shipped with the extension.
- A folder loads every `*.d.ts` inside it. Several files may extend the same `interface`, so each module can have its own file.
- `~`, `${userHome}`, `${workspaceFolder}` and workspace-relative paths are supported. Changes to the files take effect immediately.
- Declarations only (`interface`, `declare var`, `declare function`, …), no `import` / `export`.

### Highlights since 1.0.0

- **Hover** on almost every keyword: a short syntax hint, one to three sentences of explanation, and a link into the GESS Q. handbook. Hovering your own question, block or macro shows where it's defined – click it to jump there.
- **Completion as you type**, including a question's answer codes after `QUESTION.` / `QUESTION eq` / `ne` / … and the right attributes inside a `labels=` list.
- **Navigation across `#include`**: Go to Definition (`F12`), Find All References (`Shift+F12`), Rename (`F2`), Go to Symbol (`Ctrl+T`), Outline (`Ctrl+Shift+O`).
- A **"N references"** line above every question definition.
- **Diagnostics**: unbalanced brackets, an unclosed `#macro`/`#ifdef`, missing `#include` files, duplicate names, unknown `#domacro` targets, preprocessor directives that aren't the first thing on their line.
- **Real JavaScript / CSS** inside `javascript=`, `jsHandler=` and `css=`: hover, completion and parameter hints as if it were an actual `.js` or `.css` file – including the GESS Q. globals (`QDot`, `$`, `Android`, `hideq`, …).
- **Folding** for `#macro` and `#ifdef` regions, `{ … }` and block comments; snippets for question types, action blocks, grids and more; experimental auto-indent via "Format Document".
- This "What's new" panel now opens once per version automatically, and its checkbox turns it off for good once ticked.

### The most important settings

Search Settings (*File → Preferences → Settings*) for "GESS Q.":

- **`gessq.hover.referenceDetail`** (default `definition`) – how much detail a hover shows for a question/variable: `off`, `summary` (name and location only), `definition` (plus an excerpt of the definition) or `full` (everything).
- **`gessq.codeLens.definitions`** (default `questions`) – which definitions get the "N references" line: `off`, `questions`, `reusable` (also blocks/macros) or `all`.
- **`gessq.completion.autoTrigger`** (default `off`) – whether suggestions pop up on their own: `off` (only via `Ctrl+Space`), `trigger` (also after `#`/`@`/`&`) or `full` (also after a space).
- **`gessq.embeddedLanguages.enable`** (default on) – real JavaScript/CSS help inside `javascript=`/`jsHandler=`/`css=` blocks.
- **`gessq.diagnostics.enable`** (default on) – turn the diagnostics above on or off.
- **`gessq.releaseNotes.showOnUpdate`** (default on) – show this panel automatically after an update.
